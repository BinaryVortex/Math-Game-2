# Math Game 2

Math Game Built Using HTML, CSS, and JavaScript.

![Game Screenshot](./Screenshot%202024-09-16%20175540.png)

## Overview
A small, browser-based math game that helps players practice basic arithmetic (addition, subtraction, multiplication, division) with a clean UI. This project is implemented using plain HTML, CSS, and JavaScript — no frameworks required.

## Features
- Randomly generated arithmetic questions
- Score tracking
- Timer and difficulty adjustments (if implemented)
- Responsive layout for desktop and mobile

## How to Play
1. Open `index.html` in your browser (double-click the file or serve the folder with a static server).
2. Read the question shown on the screen.
3. Type your answer into the input field and submit.
4. Your score will update based on correct or incorrect answers.

## Installation / Run Locally
1. Clone the repository:

   git clone https://github.com/BinaryVortex/Math-Game-2.git

2. Open the project folder and double-click `index.html`, or serve it with a simple HTTP server:

   - Python 3:
     ```bash
     python -m http.server 8000
     ```
   - Then open http://localhost:8000 in your browser.

## Development
- The code uses vanilla JavaScript. Look for game logic in `script.js` (or similarly named JS file) and styles in `style.css` (or similarly named CSS file).
- To adjust the difficulty, timer, or scoring rules, edit the JavaScript file and reload the page.
